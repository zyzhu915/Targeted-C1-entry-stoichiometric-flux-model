# Electron-Carrier Allocation in Methanogenic Carbon Conversion

## Overview

This repository contains R scripts for the targeted C1-entry
stoichiometric flux analysis described in the manuscript **"Electrical
perturbation reorganizes microbial electron carrier allocation."**

The model examines the relative contributions of hydrogen (H2)- and
formate-mediated entry into CO2-reducing methanogenesis under
conventional anaerobic digestion (AD) and electrically perturbed
anaerobic digestion (EAD). The workflow combines measured 24-hour
metabolite changes, stoichiometric and material-balance constraints,
candidate-solution optimization, and omics-informed ranking.

## Repository contents

-   `08A5000_AD2EAD3_ONLY_STAGEA_ONLY_GLU7p264_HPC.R`\
    Stage A. Converts 24-hour measurements into model constraints,
    defines the reaction-flux variables and bounds, optimizes candidate
    flux solutions using multistart bounded optimization, and exports
    candidate solutions and diagnostic summaries.

-   `08B_STAGEB_AD2EAD3_ONLY_FULL_PFLMIN_correct_paths.R`\
    Stage B. Reads the Stage A candidate solutions, applies
    metabolite-objective cutoffs, incorporates omics-derived reaction
    capacities, calculates penalties for H2- and formate-entry
    reactions, applies the core-entry ranking gate, and exports ranked
    candidate solutions and summaries.

-   `24h2.xlsx`\
    Example name of the 24-hour metabolite workbook expected by Stage A.
    This input file is **not included** in this code-only repository.

Other required input files are described below and are not included
unless separately provided by the authors.

## Workflow

1.  **Prepare the measured constraints.** Stage A reads the 24-hour
    workbook (by default, worksheet `Sheet2`) and converts changes in
    methane, carbon dioxide, hydrogen, formate, acetate, inorganic
    carbon, lactate, and COD into model constraints.
2.  **Generate candidate flux solutions.** Stage A defines the
    stoichiometric reaction network and feasible bounds, then performs
    multistart optimization under the selected network scenario and
    parameter settings.
3.  **Rank candidates using omics information.** Stage B maps
    omics-derived reaction capacities to selected model reactions,
    evaluates candidate flux distributions, applies the specified
    objective cutoffs and core-entry gate, and ranks the retained
    solutions.
4.  **Inspect outputs.** The exported Excel workbooks contain summaries
    and diagnostic tables; RDS files preserve detailed candidate objects
    and flux parameters for downstream analysis.

## Software requirements

The scripts use R and the following packages:

-   `readxl`
-   `dplyr`
-   `tidyr`
-   `stringr`
-   `openxlsx`
-   `tibble`
-   `purrr`
-   `parallel` (included with standard R installations)

Install the required contributed packages in R, if needed:

``` r
install.packages(c(
  "readxl", "dplyr", "tidyr", "stringr",
  "openxlsx", "tibble", "purrr"
))
```

The scripts were designed for computational runs that may involve many
optimization starts. Runtime depends on the number of starts, the
selected scenario, the available CPU resources, and the machine
configuration.

## Required input files

### Stage A

Stage A requires a 24-hour metabolite workbook, named `24h2.xlsx` by
default. The script expects worksheet `Sheet2` unless another sheet is
specified. The workbook must contain the measurement headings and time
points expected by the script, including the 0-hour and 24-hour
measurements for the modeled groups (`AD2` and `EAD3`).

The Stage A script accepts command-line arguments for the working
directory, input workbook, worksheet, scenario, number of optimization
starts, and number of CPU cores. Consult the argument definitions in the
script before running it.

### Stage B

Stage B requires all of the following:

1.  The Stage A RDS file containing candidate flux solutions for the
    `Full` scenario.
2.  The converted-constraints Excel workbook generated by Stage A.
3.  The omics-derived reaction-capacity workbook used by the model (the
    script currently refers to a file named
    `09B_v3_reaction_capacity_from_02G_M00357_PFLmin_for_05A.xlsx`,
    worksheet `03_capacity_for_05A`).

**These input data files are not included in this code-only
repository.** They must be obtained separately from the authors or from
the relevant data repository, subject to applicable data-sharing
permissions.

## Important configuration note

The Stage B script currently contains local Windows absolute paths for
its working directory and reaction-capacity workbook. Before running it
on another computer or computing platform, update those paths to match
the local environment, or modify the script to use command-line
arguments or project-relative paths.

Stage B also expects Stage A outputs with specific filenames. Run Stage
A for the `Full` scenario and ensure the resulting RDS and
converted-constraints workbook are located where Stage B expects them.

Because the required input workbooks are not distributed here and the
Stage B paths require configuration, this repository should not be
considered a self-contained, immediately executable reproduction package
in its current form.

## Main outputs

Depending on the scenario and settings, Stage A writes:

-   an Excel workbook containing parameters, converted constraints,
    parameter-grid summaries, diagnostics, and candidate summaries;
-   an RDS file containing detailed candidate solutions;
-   an Excel workbook containing converted constraints.

Stage B writes:

-   an Excel workbook containing candidate audits, setting summaries,
    selected solutions, flux tables, omics-capacity mappings, and ranked
    candidate results;
-   an RDS file containing detailed scoring and ranking objects.

The exact output filenames are defined in the scripts.
